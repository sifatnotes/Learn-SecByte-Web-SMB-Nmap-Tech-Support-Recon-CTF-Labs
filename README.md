The labs are useful for cybersecurity students, CTF players, pentesters, SOC analysts, and security learners developing practical enumeration skills.

## Learning Path

A practical learning sequence is:

### 1. Web Discovery
Start with:

- Hidden Dir Hunt
- Robots.txt Recon Riddle
- FFUF Find the Hidden Paths

Learn how web resources can be identified during an authorized assessment.

### 2. Network & SMB Enumeration

Continue with:

- Shared Shadows
- ShareHunt SMB
- SMB Clues Hidden Share Hunt

Practice identifying shared network resources and understanding SMB enumeration.

### 3. Port & Service Discovery

Then work through:

- Port Sweep to Root 2
- Nmap Service Sleuth 4
- Scanline Secrets

Build familiarity with network scanning and service enumeration.

### 4. Tech Support Scenarios

Finish with:

- Hidden Clues TechSupport Trail
- Tech Support Trails
- Tech Support VPN Lab

Use these exercises to connect reconnaissance concepts with broader network-access scenarios.

## How to Use the Labs

1. Choose a lab from the collection.
2. Read the instructions provided with the exercise.
3. Work only against the authorized lab environment.
4. Identify the objective and document your findings.
5. Record useful commands, discovered services, paths, and observations.
6. Review what each discovery means from a defensive security perspective.
7. Write your own notes or methodology after completing the exercise.

Skills practiced across this collection include:

- Web reconnaissance
- Directory enumeration
- robots.txt analysis
- FFUF content discovery
- SMB enumeration
- Nmap scanning
- Service enumeration
- Port discovery
- Network reconnaissance
- VPN-related security concepts
